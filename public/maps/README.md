# Thư mục bản đồ GeoJSON

Thư mục này chứa các file GeoJSON dùng để hiển thị ranh giới hành chính trên bản đồ.

## Cách sử dụng
- Đặt file GeoJSON của phường Bình Đông (hoặc khu vực khác) vào thư mục này với tên `binh-dong.geojson`.
- File sẽ được tự động tải lên bản đồ vụ việc.
- Đường dẫn truy cập tĩnh: `/maps/binh-dong.geojson`
